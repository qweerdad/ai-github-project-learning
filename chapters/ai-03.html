案例 03：遇到 JavaScript 报错，怎么问#

导读

对应第三、七章。场景：Console 报红字，功能不正常。

❌ 低效问法#

text
我的代码报错了，怎么办？
（或只发一张报错截图，不配任何文字）

为什么不好：AI 看不到你的代码、报错全文、环境，只能猜。截图里的报错如果没复制成文字，AI 还可能读错字符。

✅ 改进问法#

text
【环境】Windows 11 + Edge，用 python -m http.server 8765 --bind 127.0.0.1 起本地服务器。
【现象】页面能打开，但点"Add"按钮任务加不进去。
【报错】Console 完整红字原文：
    Uncaught TypeError: Cannot read properties of null (reading 'addEventListener')
        at init (http://localhost:8765/script.js:660)
【我查过的】script.js 第 660 行是 taskForm.addEventListener('submit', handleAddTask)；
           index.html 里确实有 <form id="task-form">。
【问题】可能是什么原因？帮我列排查顺序，不要直接给结论。

好在哪里：环境、现象、报错原文、你已查的、还要"排查顺序"而不是"答案"——AI 会教你查，而不是替你猜。

AI 示范回答 · 教学构造，非真实记录
说明

Cannot read properties of null 说明 taskForm 拿到的是 null——document.getElementById('task-form') 没找到元素。排查顺序：

  1. index.html 里 id="task-form" 有没有拼写/大小写差异（taskform？task_form？）；
  2. script.js 是不是在 HTML 元素渲染之前就执行了（type="module" 默认 defer，一般没事，但如果你改过加载方式要查）；
  3. 是不是缓存了旧版 index.html——Ctrl+F5 强刷再看。
核实清单：AI 说了不算，逐条验证
  • 对照 id：index.html id="task-form" ↔ JS getElementById('task-form') 逐字符比对；
  • 强刷排除缓存；
  • 若 AI 说"是 X 原因"，去验证 X 是否真的成立，不是直接信。

关键习惯#

报错永远贴原文。Cannot read properties of null (reading 'addEventListener') 这一行里，null、'addEventListener'、script.js:660 三个信息各有用——转述成"它说有个东西是空的"就全丢了。
