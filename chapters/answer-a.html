练习 A 参考答案：高优先级筛选按钮#

说明

参考答案。先独立完成再对照——对照的不是"抄"，是"我的思路和参考差在哪"。

思路#

新筛选 = 一个按钮 + filter 新值 + filterTasks 认这个新值。改动同样横跨"UI / 状态 / 逻辑"三层，但比备注小得多。

改动点#

① index.html：加一个按钮（照抄现有的）#

找到三个筛选按钮所在的容器（形如 <div class="filters">），抄一个改：

html
<button class="filter-btn" data-filter="high">High</button>
说明

文字自定（"高优先级"/"⭐ High"均可）。data-filter="high" 是关键的值。

② script.js：setFilter 认新值#

setFilter 一般是读 data-filter 更新 filter 变量——只要它不做"值白名单校验"，这一步可能完全不用改。要检查的是：有没有地方写死了 ['all','active','completed'] 做校验，若有，把 'high' 加进去。

③ taskUtils.js：filterTasks 加分支（核心）#

js
function filterTasks(tasks, filter, searchQuery) {
    let result = tasks;
    if (filter === 'active')    result = result.filter(t => !t.completed);
    else if (filter === 'completed') result = result.filter(t => t.completed);
    else if (filter === 'high') result = result.filter(t => t.priority === 'high');  // ← 新增
    if (searchQuery) { /* 原有搜索逻辑不动 */ }
    return result;
}

验收对照#

  • 按钮出现、点了只显示 high → ✅；
  • 其他筛选正常 → 检查你没动 all/active/completed 分支；
  • git diff 应该只有 3 处小改动。

常见错误与点评#

错误 点评
把筛选逻辑写进 script.js 筛选是纯逻辑，应在 taskUtils.js——分层意识是考点
直接改 all 分支 会污染"全部"筛选，回归测试能抓到
忘了任务没有 priority 原版任务必有 priority（建任务时默认 medium），但严谨可写 t.priority === 'high' 已天然排除无值者

若学生答案不同但功能正确、分层合理，同样算对——评的是方法和产物，不是逐字一致。
