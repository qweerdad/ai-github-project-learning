练习 B 参考答案：相对创建时间#

说明

参考答案。先独立完成，再对照思路差距。

关键决策点（评学生的重点）#

  1. 函数放哪：相对时间格式化是纯函数（输入时间→输出字符串），放 taskUtils.js，和 formatDueDate 并列——这是分层考点；
  2. HTML 组装放哪：buildXxxHtml 放 script.js，和 buildDueDateHtml 并列；
  3. 旧数据兼容：createdAt 在 createTask 里一直存在，但理论上仍要做 task.createdAt ? ... : '' 的兜底（防御性）；
  4. 需求边界：学生是否自己定了"just now/分钟/小时/天/超期"的规则，而不是模糊一句"显示时间"。

参考实现#

① taskUtils.js：加一个 formatRelativeTime#

js
function formatRelativeTime(isoString) {
    if (!isoString) return '';
    const then = new Date(isoString);
    const diffMs = Date.now() - then;
    const mins  = Math.floor(diffMs / 60000);
    const hours = Math.floor(mins / 60);
    const days  = Math.floor(hours / 24);
    if (mins < 1)   return 'just now';
    if (mins < 60)  return `${mins} min ago`;
    if (hours < 24) return `${hours} hour${hours > 1 ? 's' : ''} ago`;
    if (days < 7)   return `${days} day${days > 1 ? 's' : ''} ago`;
    return then.toLocaleDateString();   // 超 7 天显示日期（按学生定的规则）
}
说明

注意导入处：script.js 顶部的 import 列表要把 formatRelativeTime 加进去。

② script.js：加 buildCreatedAtHtml 并在 createTaskElement 里调用#

js
function buildCreatedAtHtml(task) {
    const rel = formatRelativeTime(task.createdAt);
    return rel ? `<span class="task-created">${escapeHtml(rel)}</span>` : '';
}

在 buildDueDateHtml(task) 附近插入 ${buildCreatedAtHtml(task)}。

③ style.css：给 .task-created 一个小字号灰色样式（仿 .task-due-date）。#

④ script.test.js：单测这个纯函数#

js
it('formatRelativeTime returns "just now" for recent timestamps', () => {
    expect(formatRelativeTime(new Date().toISOString())).toBe('just now');
});
it('formatRelativeTime handles hours and days', () => {
    const h3 = new Date(Date.now() - 3*3600e3).toISOString();
    expect(formatRelativeTime(h3)).toBe('3 hours ago');
});

验收对照#

  • 新任务 → "just now"；改 createdAt 为 3h/3d 前 → 对应文案；
  • 无 createdAt 的任务 → 空字符串不报错；
  • 单测通过、老测试不挂。

常见错误#

错误 点评
函数写进 script.js 纯逻辑进 UI 文件——分层不过关
没加 import 改 taskUtils 却忘了 script 顶部 import，运行时 is not defined——好教学点
显示成 "NaN ago" createdAt 没判空，旧数据/坏数据一来就崩——旧数据兼容考点
比较用字符串直接相减 createdAt 是 ISO 字符串，必须 new Date() 转——类型意识

学生如选了"始终显示 X days ago"等其他合理规则，只要需求自定、实现正确即可。
