第五章：学会向 AI 提问，而不是只会复制提示词#

说明

本章约 90 分钟。这是第二个核心章节——AI 用得好不好，八成取决于你怎么问。

学习目标#

掌握一套在任何 AI 工具上都通用的提问方法：

  1. 描述目标而不是只说"帮我弄一下"；
  2. 给够上下文（文件、代码、环境、版本）；
  3. 把大问题拆成小问题；
  4. 要求 AI 给"可验证"的答案；
  5. 识别 AI 回答里的猜测，要求缩小修改范围；
  6. 在修改之后继续追问，形成闭环。

开始前需要#

  • 项目已跑起来（第三章）；
  • 已读第四章，知道大概结构。

5.1 提问的通用公式#

一个好问题 = 目标 + 上下文 + 约束 + 期望的输出形式

text
❌ 烂问题：「我的代码报错了怎么办」
   ——AI 不知道你是什么代码、什么报错、什么环境，只能瞎猜。

✅ 好问题：「我在 Windows 11 + Edge 上运行一个 HTML/JS 项目。
   用 file:// 打开 index.html 时页面能显示但 JS 不运行，
   Console 报错：Access to script ... blocked by CORS policy。
   我的 script 标签是 <script type="module" src="script.js">。
   请解释原因，并给我两种不装新软件的解决办法。」

后者给了：环境（Windows/Edge/file://）、现象（页面显示但 JS 不跑）、证据（完整报错原文）、线索（type="module"）、期望（解释 + 两种方案）。AI 想答错都难。

5.2 六个真实场景：从烂问题到好问题#

场景一：看不懂项目目录#

❌ 低效提问：「这个项目文件太多了，每个是干嘛的？」

为什么不好：没给目录结构，AI 只能猜"一般项目里 index.html 是入口"这种废话。

✅ 改进提问：

text
我下载了一个任务管理器开源项目，目录如下（贴文件列表）。
我学过一点 HTML/JS。请告诉我：
1. 浏览器实际运行需要哪几个文件；
2. package.json、eslint.config.js 这类文件不装 Node 能跑吗；
3. 我应该按什么顺序读这些文件。

你要检查什么：AI 说"需要 script.js"——去 index.html 里搜 <script 验证；AI 说"不需要 package.json"——把项目复制到没有 Node 的环境试试。

场景二：找不到某个功能在哪实现#

❌ 低效提问：「搜索功能在哪？」

✅ 改进提问：

text
项目里有一个搜索框可以对任务做关键词过滤并高亮。
index.html 里搜索框是 <input id="search-input">。
请告诉我应该去哪个文件搜什么关键词来找它的实现，
不要直接重写代码给我。

为什么要"不要直接重写"：你要的是定位，不是答案。AI 会告诉你搜 search-input、handleSearch 之类的线索，你自己 Ctrl+Shift+F 找到 handleSearch 函数和 highlightSearch 工具函数——找到的过程就是你学会的过程。

你要检查什么：AI 给的每个关键词都实际搜一遍，确认存在。

场景三：遇到 JavaScript 报错#

❌ 低效提问：「报错了 [截图]/ 一堆红字」

✅ 改进提问：

text
我在 Console 看到这条错误（完整粘贴原文）：
Uncaught TypeError: Cannot read properties of null (reading 'addEventListener')
    at init (script.js:xxx)

我检查过 script.js 第 xx 行是：
    taskForm.addEventListener('submit', handleAddTask);
而 index.html 里确实有 <form id="task-form">。
可能是什么原因？

核心动作：完整复制报错原文（不是转述、不是截图描述），附上 AI 需要的那几行相关代码。

你要检查什么：AI 说"可能是元素 ID 不匹配"——去 index.html 核对 id="task-form" 和 JS 里 getElementById('task-form') 是否一致。

场景四：要新增功能，先讨论方案再写码#

❌ 低效提问：「帮我给任务加个备注功能，代码发我」

为什么不好：AI 大概率给你一个"看起来完整"的大段重写——几百行新代码贴上来，你根本没法判断它改坏了什么。

✅ 改进提问：

text
我在一个任务管理器项目里想加"任务备注"功能：
每条任务可以附带一段备注文字，能编辑、能保存，
搜索时也要能搜到备注内容。

现状（贴 createTask 函数和任务对象结构）：
    { id, text, completed, priority, dueDate, createdAt }

请先不要写完整代码。请告诉我：
1. 这个功能要动哪几个文件、哪几个函数；
2. 数据上需要加什么字段；
3. 有没有我没想到的坑（比如旧数据没有新字段怎么办）。

你要检查什么：AI 提到的每个函数/文件是否真的存在（第四章的方法：Ctrl+F 搜）。AI 若提到"旧数据兼容"这种点——这是好回答的标志，说明它在真思考。

场景五：AI 给了大段重写，要求缩小范围#

典型情况：你问了个小改动，AI 回给你整个重写过的 script.js。

✅ 应对追问：

text
这个方案改动太大了。请只给我最小改动：
1. 列出需要修改的函数名和每个函数要加/改哪几行；
2. 用"修改前/修改后"的片段形式给，不要整文件；
3. 哪些原有行为可能受影响，需要我重点回归测试？

你要检查什么：把 AI 给的"修改前"片段和你文件里的真实代码逐字对比——如果"修改前"都对不上，说明 AI 在猜你的代码长什么样，这时要把真实代码贴给它纠正。

场景六：AI 编造了不存在的东西#

第四章已经见过实例：AI 说"高亮由 highlight() 函数实现"，实际是 highlightSearch()。这类错误的套路：AI 说的是"这类功能一般叫什么"，不是你项目里实际叫什么。

✅ 识别与纠正：

text
我搜索了源码，没有 highlight 这个函数，
实际找到的是 taskUtils.js 里的 highlightSearch（贴代码）。
请基于这个真实实现重新解释搜索高亮是怎么工作的。

习惯：AI 提到任何"函数/文件/配置项"，先搜一下再采信——30 秒的 Ctrl+F 往往就能识破一次编造。

5.3 两条 AI 使用路径#

本课程设计上不依赖任何特定 AI 的付费能力：

路径 你能做什么 怎么用
A. 普通聊天式 AI 粘贴代码片段/报错/目录列表提问 复制相关代码 → 描述背景 → 粘贴提问 → 把建议拿回代码里核实
B. 能读项目的 AI 编程助手 让它自己读整个项目、改代码、跑命令 给它任务说明 → 审查它的改动 → 自己测试验收

A 路线必须走通：哪怕你的"AI"只是一个聊天框，只要你会贴代码、会描述、会追问，本章所有方法都成立。B 是加速器不是前提：它能帮你搜代码，但"改得对不对"仍然要你验证——自动化越强，你越要懂 5.2 里的核实方法。

5.4 修改之后怎么继续追问#

改完代码不是对话结束，是新一轮提问开始：

text
「我按你的建议改了 createTask 和 filterTasks（贴改后代码）。
   现在功能能用，但我想确认：
   1. 旧版本存进 localStorage 的任务（没有 note 字段）会不会出问题；
   2. 备注里如果输入 <script>alert(1)</script> 会安全吗；
   3. 帮我想 5 个应该手动测试的场景。」

让 AI 帮你列测试点，你再照着逐个点一遍——这是第七章的完整方法，AI 在这里是你的"测试参谋"。

5.5 提问质量自检清单#

发出去之前，检查你的问题里有没有：

  • 目标：我到底想实现/弄清楚什么？（一句话说清）
  • 环境：操作系统、浏览器/工具版本、怎么运行的；
  • 证据：报错原文、代码片段、你实际看到的现象（不是转述）；
  • 已试过的：你查过什么、试过什么（避免 AI 让你重复做）；
  • 期望形式：要解释？要方案？要最小改动？要测试点？
  • 范围约束：「不要重写整个文件」「只改一个函数」之类的护栏。

常见失败及处理#

现象 处理
AI 回答一大段但没用上 问题太大或没给上下文——拆小、贴代码重问
AI 给的代码跑不通 把真实报错 + 你改后的代码一起贴回去让它修，别只说"不行"
AI 每次回答都不一样 正常，它本就有随机性——以"代码跑起来的结果"为唯一裁判
AI 让你装一堆东西 追问"有没有不安装新工具的办法"——本课程底线是免费工具
越问越糊涂 停止追问，回到代码：自己读那几行，往往比第十次解释管用
自检问题 · 勾选状态仅保存在你的浏览器
  • 能说出"好问题四要素"（目标/上下文/约束/期望形式）；
  • 知道为什么"不要直接要完整代码"，而要先要方案；
  • 能举出两个"AI 会编造的东西"（函数名、行号、文件路径）；
  • 知道 A/B 两条路径的差别，明确自己的主线是 A；
  • 发问题前会过一遍 5.5 清单。
过关标准

随便挑一个你还没弄懂的项目细节（比如"拖拽排序怎么实现的"），用本章方法写一条提问，发出去——答案里 AI 给的每个线索都能被你在源码里搜到/验证。做到即过关。
