遇到问题怎么办（自助排查）#

说明

卡住了先看这里。大多数问题 5 分钟内能自己解决——而且"把问题说清楚"本身就是本课程要练的能力。

网站相关#

打不开页面 / 页面一片空白#

  • 你是双击 index.html 打开的吗？应该在本课程文件夹的最外层找到它，不要在 chapters/ 里面找别的入口；
  • 如果浏览器提示"文件已移动或删除"，多半是解压不完整——重新解压一次 ZIP，并保持文件夹结构原样，不要单独移动任何一个 html 文件；
  • 用 Edge 或 Chrome 打开，别用很旧的浏览器。

图片裂了 / 排版很怪#

  • 原因同上：assets/、images 文件夹必须和 index.html 保持原有的相对位置，整体复制、不要只拷单个文件；
  • 页面能看但样式全没了 → assets/ 文件夹丢了或改名了，重新解压。

动手环节相关#

VS Code 打开项目时弹"是否信任此文件夹"#

正常现象，点"是，我信任此作者"。这是编辑器对陌生代码的安全提示，第三章有截图说明。

提示 "python 不是内部或外部命令"#

Python 没装或装的时候没勾选 Add Python to PATH。两个办法：

  1. 重新安装 Python（python.org 免费下载），安装时一定勾选 Add Python to PATH；
  2. 或者干脆不用 Python——VS Code 装 "Live Server" 扩展，右键 index.html → "Open with Live Server"，效果一样。

本地服务器怎么启动、怎么退出#

在项目文件夹里（里面要有 index.html）：

text
python -m http.server 8765 --bind 127.0.0.1

看到 Serving HTTP on 127.0.0.1 port 8765 就启动好了，浏览器访问 http://127.0.0.1:8765/。

  • 这个黑窗口不能关，关了服务器就停了；
  • 想退出：在窗口里按 Ctrl + C；
  • 弹防火墙提示不用点"允许"——--bind 127.0.0.1 只服务本机。

页面能打开但功能全失效（输入没反应）#

先按 F12 打开浏览器开发者工具，看 Console（控制台）有没有红色报错。

  • 地址栏是 file:///... → 你双击打开了文件而不是走服务器，回到上一条用本地服务器访问（第三章专门讲这个坑）；
  • 地址是 http://127.0.0.1:8765 但还有报错 → 把报错原文复制下来，按下面的模板问 AI。

AI 给的方案和我的代码对不上#

太正常了——AI 没见过你的文件，是猜的。做法：

  1. 用 Ctrl+F 在源码里搜 AI 说的函数名/文件名，看看到底存不存在；
  2. 把你实际看到的代码贴回去纠正它："我搜了，我们这里没有这个函数，实际是……"；
  3. 第四章、第五章专门教这套核实方法，侧栏「AI 提问示例」里的「06 AI编造了不存在的东西」也是这个场景。

求助 AI 时提供什么（直接套模板）#

text
【我在做什么】按《AI时代的GitHub开源项目实战》第X章操作，目标是______
【预期结果】应该______
【实际结果】却______（页面现象/报错原文，别转述）
【报错原文】<把 Console 红字或命令行报错原样贴上>
【我的环境】Windows 11 + Edge，python -m http.server 8765 --bind 127.0.0.1
【我已试过】______（换浏览器/重启服务器/检查过某文件，列出来）
【请回答】可能的原因 + 下一步排查方向（先别给大段代码）

三条铁律：报错贴原文、说清楚你试过什么、先要排查方向再要代码。

还是解决不了？#

  1. 翻到对应章节末尾的"常见失败及处理"表（每章都有）；
  2. 换侧栏「AI 提问示例」里对应的场景，照着里面的问法问一遍；
