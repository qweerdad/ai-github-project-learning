课程说明#

说明

开始前花 5 分钟读完这一篇，能少踩不少坑。

你将获得的能力#

按顺序学完八章并做完练习，你将能独立地：

  1. 判断一个 GitHub 项目适不适合自己；
  2. 不用 Git 也能下载并固定版本；
  3. 用免费工具把项目跑起来，认出"假跑起来"；
  4. 借助 AI 读懂项目结构和一条完整数据流；
  5. 提出小需求并让 AI 帮你做局部修改；
  6. 用测试和开发者工具验证修改，发现 AI 的错误；
  7. 向别人讲清楚你做了什么、怎么验证的；
  8. 把整套方法迁移到下一个陌生项目。

硬件与软件要求#

项 要求 说明
电脑 普通 Windows 10/11 笔记本 8GB 内存或同级即可，不需要 GPU
浏览器 Edge 或 Chrome 任一 开发者工具（F12）是课程必备
Python 3.x（装时勾 Add to PATH） 仅用来起本地服务器，python -m http.server --bind 127.0.0.1
VS Code 免费下载 推荐的代码编辑器，不强制
AI 工具 任一免费聊天式 AI 课程不依赖任何付费能力

不需要安装：Git（可选）、Node.js（可选，只有想跑单元测试才用）、Docker、Linux。

说明

如果你的电脑连 Python 都没装/装不上：VS Code 的 "Live Server" 扩展也能起本地服务器，效果一样（3.3 节有说明）。

建议学习节奏#

不要试图一天刷完。这是动手的课，不是看的课：

阶段 内容 建议
第 1 天 第一、二章 读 + 浏览真实 GitHub 仓库
第 2 天 第三章 动手：跑起来，把 file:// 坑踩一遍
第 3 天 第四、五章 动手：读码 + 练提问
第 4~5 天 第六章 核心动手：做完备注功能
第 6 天 第七章 动手：把测试清单跑一遍
第 7 天起 第八章 + 练习 练习 A、B 必做，C 尽力
导读

全程约 7~10 天、每天 1~2 小时。第六章是全课最重的动手章（需要逐行跟做并验证），留出两天以上是正常节奏；练习 C 视所选项目难度，可能再花 2~4 小时。上面的天数是建议下限而非承诺——卡住了就慢下来，按自己的节奏走。

文件在哪里（第一次对照）#

课程里你最常用的几个入口：

  • 要跑的源码：左侧「下载中心」→ taskflow-original.zip，解压得到 TaskFlow-40dcd30/——直接用，不用联网下载；
  • 改好的成品：下载中心 taskflow-notes-edition.zip——第六章的对照答案，做完第六章再打开；
  • 改动的完整对照：左侧「改动对照」页，或下载中心的 changes.diff；
  • 所有截图：已直接放在各章正文里，点击可放大；
  • 练习：侧栏「学生练习」组；答案：侧栏 ⚠「参考答案」组（先别看）；
  • 卡住了：侧栏「遇到问题怎么办」页。

三条学习纪律#

这门课的效果完全取决于你怎么学，三条纪律：

  1. 每个操作自己动手做一遍——截图里的东西在你的电脑上也要出现一次；
  2. 先自己想，再问 AI，最后自己验证——每章都有这个节奏，别跳过第一步；
  3. 遇到问题先看"常见失败及处理"——每章末尾都有，大概率你的坑在里面。

常见问题#

Q：我英语不好，README 看不懂怎么办？ A：这正是第二章教你的——只抓"干什么/什么技术/怎么跑"三个问题，其余跳过。也可以把 README 整段贴给 AI 让它翻译并提取这三点。

Q：我的 AI 是 XX 品牌，教程适用吗？ A：适用。课程是"模型中立"的——教的是提问方法（给上下文/给证据/要方案不要代码），任何能聊天的 AI 都成立。不依赖"能读文件/能跑命令"的高级能力。

Q：卡住超过半小时怎么办？ A：先对照片章末"常见失败"表 → 不行就用第五章方法把【目标+环境+报错原文+已试过的】整理成问题问 AI → 再不行就先跳过当前小节往后走，往往后面会回头解开。实在不行看侧栏 ⚠「参考答案」组——但看完要自己重做一遍，光看不算会。

Q：一定要做练习 C（换项目）吗？ A：A、B 是必做；C 是挑战项，但它才是"真学会"的试金石。哪怕没做完，走一遍前五步也很有收获。

Q：这个教程能拿去交作业/发文章吗？ A：教程本身可自由学习使用。但注意：你产出的"项目报告"必须是你自己做的、能讲清楚的——这才是课程要的成果，抄来的不算数。
